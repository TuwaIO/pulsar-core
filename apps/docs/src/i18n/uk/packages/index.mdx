# Пакети

Pulsar складається з одного основного пакета, незалежного від мереж (**L3**), і трьох пакетів **L4**, побудованих на основному пакеті: адаптерів для кожної платформи блокчейнів (EVM, Solana) і прив’язок React для сховища основного пакета. Встановіть основний пакет і лише ті пакети L4, які потрібні вашому застосунку. Усі пакети оголошують свої Web3-бібліотеки та бібліотеки стану як peer-залежності, тож ваш застосунок тримає лише одну копію `zustand`, `immer`, `viem`, `@wagmi/core`, `@solana/kit` чи `react`.

Сторінка кожного пакета починається з README пакета (того самого тексту, що опубліковано в npm), за яким іде повний список його експортів. Сторінку кожної функції, класу, типу й константи згенеровано з вихідного коду TypeScript та його JSDoc, тож довідник завжди відповідає випущеному коду. README пакетів і довідник подано англійською.
